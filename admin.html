📝 সব পেজের লেখা সম্পাদনা

সাইটের দৃশ্যমান টেক্সটগুলো JSON আকারে বের করে পরিবর্তন করুন। একই লেখা একাধিক জায়গায় থাকলে সব জায়গায় বদলাবে। Deposit পেজের নির্দেশনা/নাম্বারসহ টেক্সটও এখানে সম্পাদনা করা যাবে।
প্রথমে Load করুন, তারপর মান পরিবর্তন করে Save করুন।

💳 Deposit পেজের তথ্য

Deposit পেজে প্রদর্শিত নির্দেশনা, পেমেন্ট পদ্ধতির নাম, নম্বর, শিরোনাম ইত্যাদি Text Editor থেকে পরিবর্তন করুন। নিচের সেটিংস JSON একই ব্রাউজারে সংরক্ষিত হবে।

🎮 HTML Game / Slot যোগ করুন

একটি HTML গেম ফাইল আপলোড করলে সেটি Game Categories-এ যোগ হবে। ফাইলটি LocalStorage-এ সংরক্ষিত থাকবে; বড় ফাইল ব্রাউজারের স্টোরেজ সীমা ছাড়াতে পারে।
